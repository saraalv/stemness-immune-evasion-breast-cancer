# SCIE
¡Hola! Este es el repositorio de mi trabajo de fin de máster:
"Interacción entre stemness y evasión inmune en cáncer de mama: un enfoque basado en Machine Learning y firmas génicas."
Para estudiar esta interacción se utilizaron datos de bulk RNA-seq provenientes de TCGA y AURORA US, sobre los cuales se aplicaron métodos de análisis de co-expresión y técnicas de machine learning. En primer lugar, se construyó una red de co-expresión mediante WGCNA con el objetivo de identificar módulos de genes co-expresados y se evaluó si estos módulos estaban enriquecidos en genes asociados a stemness o inmunogenicidad, y si mostraban correlaciones relevantes entre sí. A partir de los módulos identificados, se entrenaron modelos de Random Forest para seleccionar los genes más informativos de la interacción entre estos dos procesos biológicos. Además, se evaluó la capacidad predictiva de estos modelos. Los modelos mostraron un rendimiento robusto en la clasificación de muestras según sus perfiles funcionales. Por último, se realizó un análisis de enriquecimiento Gene Ontology sobre las listas de genes más informativos, dónde se identificaron rutas biológicas relevantes relacionadas con la señalización inmunitaria y la diferenciación celular.
